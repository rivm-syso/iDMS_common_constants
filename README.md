# iDMS_common_constants

## Description

A lightweight package containing shared constants across iDMS repositories.

It serves as the contract between components like iDMS-web and iDMS-services, ensuring consistent usage of iRODS AVU (Attribute-Value-Unit) attribute names and metadata keys 

## Usage

The package can be installed from our local package repository, using:

  export PIP_EXTRA_INDEX_URL="https://${GITLAB_USER}:${GITLAB_TOKEN}@gitlab.rivm.nl/api/v4/groups/133/packages/pypi/simple"
  pip install idms-common-constants
